     3→## Project Status (Initial Build Complete)
     4→
     5→**App:** Web Pro Record — a fully client-side, bilingual (EN/AR) screen + webcam + microphone recorder built on Next.js 16. No backend, no AI APIs, no uploads. All recording happens in the browser via native Web APIs (`getDisplayMedia`, `getUserMedia`, `MediaRecorder`, Canvas `captureStream`, `AudioContext`).
     6→
     7→### Architecture
     8→- `src/app/layout.tsx` — Geist + Cairo (Arabic) fonts, metadata, ThemeProvider (next-themes, dark default)
     9→- `src/app/globals.css` — custom emerald theme (light/dark), Arabic font wiring, recorder styles (rec-pulse, hero-aura, dot-grid, custom scrollbar)
    10→- `src/lib/i18n.ts` — full EN/AR dictionary (~150 keys), `translate()`, `isRtl()`
    11→- `src/lib/recorder-utils.ts` — formatDuration/Bytes/Resolution, `pickMimeType()` (vp9→vp8→h264→webm→mp4), `detectFeatures()`, `enumerateDevices()`, `computeCanvasSize()`, `qualityToVideoBitrate()`, `drawRoundRect()`
    12→- `src/hooks/use-recorder.ts` — the core recorder hook (state machine + media logic). Accepts a `canvasRef` param (kept out of return to satisfy `react-hooks/refs`). Manages: idle webcam preview loop, countdown, screen capture, mic, system-audio detection, canvas compositing (screen base + webcam overlay with shape/position/size/margin/border/shadow + optional watermark), AudioContext mixing (mic + screen audio → MediaStreamAudioDestinationNode), MediaRecorder with negotiated MIME + configurable bitrates, chunk collection, onstop blob/URL building + track cleanup, screen-share-ended handling, pause/resume timer, mic level meter (AnalyserNode), full reset/record-again/download/copy-details.
    13→- `src/components/recorder/` — header, hero, control-panel, live-preview, final-recording, help-section, footer
    14→- `src/app/page.tsx` — orchestrator: lang state + `document.dir` sync, canvasRef ownership, error/warning → toast, browser-recommendation banner (non-Chromium), unsupported blocker, floating recording status chip, sticky footer (`min-h-screen flex flex-col` + `mt-auto`)
